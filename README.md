# AutoReg Studio

เว็บแอปพลิเคชันสำหรับช่วยลงทะเบียนออนไลน์อัตโนมัติจากไฟล์ Excel

## คุณสมบัติเด่น
- 🎨 ดีไซน์สีขาว คลีน มินิมอล ใช้งานง่าย
- 📄 รองรับไฟล์ Excel (.xlsx, .xls) หรือ CSV ที่มีเฉพาะรหัสนักเรียน 1 คอลัมน์
- 🔒 ใช้ข้อมูลเดิมในระบบทั้งหมด 100% (ไม่เปลี่ยนชื่อ เบอร์โทร หรือความสัมพันธ์)
- ⏭️ ข้ามคนที่เคยลงทะเบียนสำเร็จแล้วอัตโนมัติ (ไม่ยิงซ้ำ)
- 🔀 สุ่มลำดับคิว (Shuffle Queue Order) เพื่อไม่ให้เรียงตามเลขรหัสนักเรียน
- ⏱️ สุ่มช่วงเวลาหน่วงธรรมชาติ (Random Jitter 12–35 วินาที) ทำให้เวลา Timestamp ใน Google Sheets กระจายตัวเป็นธรรมชาติ
- 📊 ส่งออกรายงานสรุปผลเป็นไฟล์ Excel (.xlsx)

## โครงสร้างไฟล์
- `index.html` : โครงสร้างหน้าเว็บ
- `style.css` : สไตล์การแสดงผล (Clean White Minimal)
- `app.js` : ตรรกะการประมวลผลและการเรียก API
